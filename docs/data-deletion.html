Fridge Manager 利用データの削除案内

施行日: 2026年8月1日

公開URL: https://quotto.github.io/fridge-manager/data-deletion.html

アプリを利用できる場合

  1. アプリの設定画面を開きます。
  2. 「すべての利用データを削除」を選びます。
  3. 削除後に復元できないことを確認して、「完全に削除」を選びます。

この操作により、端末内の全食材データ、一時画像、Firebase匿名ユーザーを削除します。

アプリを利用できない場合

本アプリの匿名認証は、メールアドレスなど利用者が本人性を示す情報と結び付けていません。そのため、アプリ外から特定の匿名ユーザーを安全に識別して削除することはできません。

削除方法について確認が必要な場合は、Googleフォーム（準備中）からお問い合わせください。

上記は仮URLです。Googleフォーム準備完了時に有効なURLへ差し替えます。

削除後も一定期間残る情報

  • Firebase Authenticationのバックアップからの削除完了には最大180日を要する場合があります。
  • App Checkのリプレイ保護tokenは最大30日保持されます。
  • Crashlytics情報とAWSの本番アプリケーションログは90日保持されます。
  • 提供者のセキュリティ記録、クォータ・冪等性管理情報、集計情報は各保持期限まで残る場合があります。
